# RetailPro - Ventas_Tech_DB

## 📊 Descripción general

**RetailPro - Ventas_Tech_DB** es un proyecto de análisis de datos orientado al estudio de las ventas de una empresa ficticia del sector retail tecnológico.

El proyecto contempla la creación y consulta de una base de datos relacional de ventas, el desarrollo de consultas SQL avanzadas para obtener indicadores y hallazgos de negocio, y la preparación de un modelo dimensional para visualización mediante herramientas de Business Intelligence.

El objetivo principal es transformar los datos transaccionales de ventas en información útil para la toma de decisiones comerciales, analizando aspectos como:

* Facturación total y evolución mensual.
* Cantidad de órdenes y comportamiento del ticket promedio.
* Rendimiento y concentración de ventas por producto.
* Comportamiento y recurrencia de clientes.
* Análisis cruzado de información mediante `JOINs` complejos.
* Consolidación de ventas por canales de distribución.
* Preparación de indicadores comerciales para tableros de control en Power BI.
